# Служебный портал Vibe RP

Требуется Node.js 24. Запуск из корня репозитория: `node backend/server.mjs`. Открыть http://127.0.0.1:18743/office.html. Сайт и API обслуживаются одним процессом. По умолчанию SQLite хранится в домашнем каталоге оператора в .viberp-portal. PORTAL_DATA задаёт постоянный каталог вне публикуемых файлов. PORTAL_WEB переопределяет путь к docs.

Для выдачи одноразовой ссылки запустите с теми же PORTAL_DATA и PORTAL_ORIGIN: `node backend/server.mjs invite "Название ведомства" employee` (или manager). Ссылка действует сутки. Получатель самостоятельно выбирает пароль. Руководитель видит документы только своего ведомства.

Для внешнего доступа разместите процесс за HTTPS reverse proxy, задайте PORTAL_ORIGIN равным внешнему origin и PORT равным порту локального процесса. Переносите базу штатной резервной копией SQLite. На GitHub Pages доступны только публичные страницы. После развёртывания разместите ссылку на HTTPS-кабинет на странице office.html публичного сайта.
