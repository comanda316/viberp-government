# State of San Andreas
Государственный портал Vibe RP. Публичный справочник и служебный кабинет для Qbox.

## Публичный справочник

В `docs/` находится статический сайт с локальным поиском по 27 правовым актам. Откройте `docs/index.html` либо выберите в GitHub Settings → Pages публикацию из ветки main и каталога /docs. Тексты в репозитории представляют собой снимок. Обновления публикуются в [State Bulletin](https://newlrp.gitbook.io/san-andreas-state-bulletin/).

## Доступ из FiveM

Поместите каталог репозитория с `fxmanifest.lua` в `resources/[local]/viberp-government`. Добавьте `ensure viberp-government` в server.cfg и запустите ресурс. Команда `/bulletin` открывает справочник. Кнопка «Закрыть» возвращает управление игре.

Служебный вход и работа с персональными делами находятся в разработке.
